# Validador Shopify

Abrí `index.html` en tu navegador, elegí el CSV y descargá el resultado. El archivo se procesa en tu dispositivo. También podés usar la versión de Python desde la terminal.

Con Python 3, ejecutá `python validar.py ejemplo.csv salida.csv`. Usá la plantilla incluida para productos simples, un handle único por producto y punto decimal. El archivo de destino debe ser nuevo. Revisá la vista previa de importación en Shopify antes de confirmar.
